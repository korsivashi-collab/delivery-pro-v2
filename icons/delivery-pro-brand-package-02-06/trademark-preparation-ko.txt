배송 경로 PRO — 상표 출원 준비 자료
작성일: 2026-10-10 / 대상: 최신 비교 시안 02, 06

1. 자료의 상태
이 묶음은 로고 이미지와 출원 입력 준비용 자료입니다. 접수된 출원서, 등록증, 등록 가능 의견서가 아닙니다.
실제 제출·납부·선행상표조사는 진행하지 않았습니다. 출원인과 지정상품 확정 전에는 제출하지 마세요.
생성 이미지는 승인된 시안을 바탕으로 정리한 래스터 마스터입니다. 작은 곡선·자간 차이가 있을 수 있으므로 제출 전 견본을 최종 확인하세요.
실제 벡터 원본(SVG/AI/EPS)은 포함하지 않습니다. PNG를 SVG에 넣은 파일을 벡터 원본으로 표시하지 않습니다.

icon-pro-1024.png: 큰 앱 아이콘 검토용. apple-touch-icon-180.png: 180px 웹앱 홈 화면용.
header-logo-06-320/640/1280.png: 06 전체 로고, 비율 보존, 흰 배경. 밝은 헤더에 사용.
logo-02-source.png / logo-06-source.png: 이미지 생성 원본. 고해상도 벡터 파일이 아님.
trademark-02-color-300dpi.jpg/png: 02 심볼+배송 경로 PRO 전체 결합 견본.
trademark-06-color-300dpi.jpg/png: 06 글자+경로선+PRO 전체 결합 견본.
trademark-02-symbol-300dpi.jpg: 앱에서 실제 사용하는 심볼 단독의 별도 출원 검토용.
견본은 900x900px, 300dpi, 흰 배경으로 제작했습니다. 인쇄 크기는 7.62x7.62cm입니다.
이 정사각형 캔버스는 편의 규격이며 일반상표의 필수 8cm 규격이라고 단정하지 않습니다.
공식 특허로 안내: JPEG·PNG, 300~400dpi(300dpi 권장). 일반상표는 A4 내 선명하게 작성.
실제 전자출원 화면의 파일 용량·입력 조건이 우선합니다. 접수 화면 업로드 검증은 미실시입니다.
두 전체 로고 견본과 심볼 단독 견본은 서로 다른 표장입니다. 하나의 출원 견본으로 합쳐 제출하지 마세요.

3. 표장 설명 초안 — 검토용, 설명 제출 필요 여부는 출원 화면에서 확인
02 전체: 파란 둥근 사각형 안에 흰 연결 경로와 세 개의 지점이 배치되고, 아래에 한글 배송 경로와 영문 PRO가 결합된 표장.
06 전체: 왼쪽의 남색·파란색 둥근 사각형 두 개를 흰 연결 경로가 잇고, 오른쪽에 배송, 경로, PRO를 세 줄로 배치한 결합표장.
02 심볼: 파란 둥근 사각형 안의 연결 경로와 세 지점으로 구성된 도형 표장. 글자는 포함하지 않음.
유형 검토: 문자·도형·색채가 결합된 일반상표. 색채만으로 된 상표와 구분.

4. 출원인 입력 준비 — applicant-info.csv에 기입
개인/법인 구분, 출원인 성명 또는 법인명, 특허고객번호, 주소, 우편번호, 연락처, 이메일, 대리인 여부를 확정합니다.
개인 식별번호와 민감정보는 이 공개 자료에 적지 말고 공식 제출 화면에서만 입력하세요.
출원인 명의는 추측해 채우지 않았습니다. 필요에 따라 특허고객번호 부여·전자서명 수단을 먼저 준비합니다.
대리인에게 맡기는 경우 위임장 등 추가서류를 해당 대리인에게 확인합니다.

5. 지정상품·서비스 검토 초안 — 한국 고시 명칭 확정 전 초안
09류 검토: 다운로드 가능한 배송 경로 최적화용 소프트웨어 / 다운로드 가능한 배송 관리용 모바일 애플리케이션.
42류 검토: 배송 경로 최적화 및 배송 관제를 위한 SaaS / 온라인 비다운로드 소프트웨어 제공 서비스.
09류는 앱·다운로드 소프트웨어, 42류는 온라인 소프트웨어 서비스라는 사업 형태에 따른 검토 후보입니다.
위 한국어 문구는 사업 설명 초안이며 고시 지정상품 명칭으로 확인 완료된 목록이 아닙니다.
공식 상품조회에서 인정 명칭과 유사군을 대조하고 실제 제공 범위에 맞게 확정하세요.
배송 소프트웨어를 제공한다는 이유만으로 실제 운송·배송 서비스까지 임의로 추가하지 않았습니다.

6. 선행상표 확인표 — 조사 미실시
KIPRIS에서 배송경로, 배송 경로, 배송경로PRO, 배송 경로 PRO, DELIVERY ROUTE PRO 등을 검색합니다.
동일·유사 명칭뿐 아니라 경로·위치핀·연결점 도형과 해당 지정상품을 함께 비교합니다.
기록 항목: 검색일, 검색어, 상품류, 후보 출원/등록번호, 권리자, 상태, 지정상품, 도형 비교, 검토 결론.
검색 결과가 없다는 것만으로 등록 가능을 확정하지 않습니다. 필요하면 변리사에게 두 결합표장과 심볼 단독을 함께 검토 요청합니다.

7. 제출 전 순서
① 전체 결합표장 02·06 및 심볼 단독 중 실제 출원 대상을 확정.
② 최종 견본의 한글·PRO·모양·색·비율을 확인하고 이후 사용 기준을 고정.
③ 선행상표 확인 및 지정상품 확정.
④ 출원인·특허고객번호·대리인·서명 준비.
⑤ 특허로의 공식 상표등록출원서에 입력하고 해당 견본을 첨부.
⑥ 서식 검증·제출·수수료 확인 및 납부, 접수 결과 보관.
⑦ 보정·심사 결과에 대응. 출원만으로 등록 완료 표시를 하지 않음.
아직 필요한 사용자 정보: 출원인 명의, 주소·고객번호, 실제 사업범위, 출원 대상 선택, 선행상표 검토 결과.

8. 제작 기록과 한계
승인 기준: 최신 비교판 02·06. AI 이미지 생성으로 분리 정리한 뒤 요청 규격으로 크기·여백을 맞춤.
직접 사용하던 노란 PRO 아이콘은 수정·덮어쓰기하지 않았습니다. 프로그램·설정 파일도 변경하지 않았습니다.
새 이미지의 앱 실제 적용·스토어 심사·상표 등록·제3자 권리 비침해는 검증하지 않았습니다.
AI 생성이라는 사실 자체로 권리 충돌이 없다고 판단하지 않습니다. 실제 출원은 최종 법률 검토와 심사를 거칩니다.
